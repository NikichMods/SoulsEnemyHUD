Ветка `fix/safe-game-thread-scheduler` заменяет только Lua async setup на один
`LoopInGameThreadWithDelay(1000, ...)` с отменой по handle. Ошибка setup делает
собственные callbacks неактивными, пытается восстановить виджеты и затем отменяет
таймер. Прежние Tick hooks и алгоритмы/порядок привязки не заменяются; `Boss.stop`
добавляет только чистую Lua-остановку существующего моста.

Это профилактика риска, а не установленная причина/исправление вылета HildaSoftLight.
Readiness, API и пределы — SCHEDULER_READINESS.md. CombatHUD0.4.1 уже принят,
но этот кандидат требует своей отдельной игровой проверки. Main/release0.3.1
не меняются.

## Результат проверки 0.3.0 и передача, 2026-10-28

Кандидат 0.3.0 **не принят**: пользователь показал два кадра с читаемой латиницей
вместо ожидаемых Aphes-глифов и изменением ширины/разрядки верхней строки во время
боя. Третий кадр — штатные декоративные названия локации — принят как визуальный
референс. Причины обоих симптомов не установлены; зависимость размера от текущего
HP — гипотеза пользователя, не подтверждённый диагноз. Код уже измеряет внешний
`#BossHP`, а не `.cur_val`. См. уточнение требований и feedback в VERIFIED_RUNTIME.md.

Желаемая надпись — визуально непонятное письмо как у штатных названий локаций,
не читаемая латиница. Предыдущее согласование транслитерации не означало принятия
такого отображения. Предел ширины — 90% полной полоски, примерно по 5% с каждого
края; при неизменных имени/экране/настройках размер и разрядка должны быть стабильны
независимо от HP/урона. Короткое имя остаётся крупным. Урон справа сохраняется.

Пользователь переносит координацию в обычный ChatGPT через GitHub; локальный Codex
используется по узкому заданию для machine-only исследования/сборки/установки.
Применять актуальный DevRules WORKING_RULES.md и раздел user-mediated handoff в
CODEX_WORKFLOW.md. Общие исследования: NikichMods/Asterigos-Research,
docs/RESEARCH_INDEX.md; применим R-007 в docs/VERIFIED_RUNTIME.md.
Исследование/исправление runtime в этом сегменте передачи не выполнялось.

Установленные pak и main.lua сверены с manifest 0.3.0: совпадают. Сборка и
замороженная 0.2.0 не менялись. Дальнейшая работа — в feature/boss-aphes-name;
современный main содержит отдельный план разделения репозиториев, но миграция
не является частью этого исправления. После проверенного организационного переноса каноничен NikichMods/SoulsEnemyHUD;
точный исходный коммит и историческая запись остаются в AsterigosMods.
